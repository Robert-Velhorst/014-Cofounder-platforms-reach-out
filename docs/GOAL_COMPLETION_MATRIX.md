# Goal completion matrix

Updated: 2026-10-02. Overall goal: **not complete**.

This replaces the historical range-based table, whose phase subjects did not match
this specification and whose broad Verified labels did not establish the current
worldwide public-beta outcome. Existing working functionality is preserved.
Partial means bounded implementation or evidence exists, not that the feature is
absent; Missing identifies a named requirement without a supported complete path.
No phase is promoted from file existence or green structural checks alone.

## Structural verification is not completion

The requirements-integrity gate checks the exact phase/title sequence, allowed
status vocabulary, all 12 source-named document artifacts and local evidence-path
containment/existence. It cannot prove
functional correctness, licensing, provider approval, hosted operations, legal
acceptance, or that any phase has met its definition of done. It always
reports completion as unproven. Final approval must inspect substantive evidence
for **every phase and additional requirement** and retain the entire goal.

The workstation tunnel launcher is retired. Hetzner deployment, migration, hosted acceptance and rollback remain open operator gates under `DEPLOYMENT_TARGET.md`.
