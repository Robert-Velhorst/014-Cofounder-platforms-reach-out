## Implemented behavior

An import error conservatively marks the result uncertain, not definitely unsaved.
CSV, evidence reference and declaration are locked. The user can retry the exact
payload and original idempotency key; a successful result unlocks the fields.
Editing instead requires a separate record-review button and browser confirmation.
Declining keeps the lock. Accepting unlocks without submitting or overwriting
anything; changing CSV/evidence still clears the rights acknowledgment and changes
the next request signature. Confirmed server refusals also use this conservative
lock; the application does not infer a rollback from an error string.

While pending/uncertain, a before-unload listener requests the browser's native
warning. It cannot guarantee prevention of closing/crashing or protect SPA logout.
Receipt identity is still in tab memory; this is not cross-session recovery.
The recovery notice, retry label and explicit edit acknowledgment support EN/NL;
At that earlier checkpoint the rest of the detailed CSV importer and server
errors remained English; the subsequent interface repair above supersedes the
client-copy limit, not the server-language or cross-session limits.
The long Dutch recovery button wraps on mobile.

React guidance kept the input-lock decision derived from pending/uncertain state.
The effect is only the before-unload event subscription, not derived-state copying.
No server schema, endpoint, idempotency transaction, matching/permission/capacity
rule changed. No new source or contact authorization is granted.

## Action semantics

| Action | API/data/error effect |
| --- | --- |
| Import CSV | Existing prospects.importCsv payload with owner/declaration/key; error records uncertain state and keeps exact input/key |
| Retry unchanged import | Same mutation with exact retained payload/key; receipt replay is a confirmed stored result, not another import |
| Allow editing after checking records | Local confirmation only; unavailable account/in-flight guard refuses; decline retains lock |
| Change CSV/evidence | Local unsaved change; acknowledgment/result cleared, new request identity only on next submission |
| Switch workspace tabs | Parent import state/key persist; no submission caused by navigation |
| Reload/leave browser | Native warning requested during uncertainty; browser/user policy governs actual prompt |
